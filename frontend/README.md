# Frontend — Gestor de Reservas de Hotel

React 19 + Vite + TypeScript + MUI + React Router + Axios.

```bash
npm install
cp .env.example .env     # en Windows: copy .env.example .env
npm run dev              # http://localhost:5173
npm run build            # compila y revisa tipos
npm run lint
```

Necesita los dos backends encendidos (8080 y 8081). Ver `ARQUITECTURA.md` y `CONVENCIONES.md` §6.
